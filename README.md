## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:5173`

## 📊 Data Management

All content is managed through JSON files in the `src/data/` directory:

- `site.json` - Site-wide settings and contact information
- `services.json` - Service offerings and details
- `industries.json` - Industries we serve
- `training.json` - Training programs
- `gallery.json` - Project portfolio
- `clients.json` - Client testimonials

## 🔧 Customization

1. **Update Content** - Modify JSON files in `src/data/`
2. **Change Colors** - Update Tailwind classes or CSS variables
3. **Add Pages** - Create new components in `src/pages/`
4. **Modify Layout** - Edit components in `src/components/`
